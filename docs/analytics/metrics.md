# 户部 - 数据分析指标

## 核心指标定义

### 1. 解决率计算

```
解决率 = (显式评价 + 行为信号 + 对话闭环) / 总会话数

显式评价 (40%): 用户说"谢谢/明白了"
行为信号 (30%): 是否重复问、是否开启新会话
对话闭环 (20%): 短对话闭环检测
语义判断 (10%): LLM判断意图是否达成
```

### 2. 满意度计算

```
满意度 = Σ(评分 × 权重) / 总评分数

评分来源:
- 显式评分 (1-5分)
- 情感分析评分
- 行为推断评分
```

### 3. 转人工率

```
转人工率 = 转人工会话数 / 总会话数

转人工原因分类:
- 知识不足 (可优化)
- 能力不足 (可优化)
- 客观限制 (保持转人工)
- 系统问题 (修复BUG)
```
