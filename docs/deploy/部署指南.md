# 部署指南

## 一、Docker部署（推荐）

### 1.1 构建镜像
```bash
cd /Users/xiaohuzhuanshu/java/projects/backend/ai-customer-service
mvn clean package -DskipTests
docker-compose -f deploy/docker-compose.yml build
```

### 1.2 启动服务
```bash
docker-compose -f deploy/docker-compose.yml up -d
```

### 1.3 健康检查
```bash
curl http://localhost:8080/api/chat/health
```

## 二、本地部署

### 2.1 环境准备
```bash
# 安装Java 17
brew install openjdk@17

# 安装Maven
brew install maven

# 安装MySQL
brew install mysql

# 安装Redis
brew install redis
```

### 2.2 启动服务
```bash
# 启动MySQL
brew services start mysql

# 启动Redis
brew services start redis

# 启动应用
java -jar ai-customer-service-starter/target/ai-customer-service-starter-1.0.0-SNAPSHOT.jar
```

## 三、配置说明

### 3.1 数据库配置
修改 `application.yml`:
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/ai_customer
    username: root
    password: your_password
```

### 3.2 Redis配置
```yaml
spring:
  redis:
    host: localhost
    port: 6379
```

## 四、监控

### 4.1 健康检查
- 端点：`/actuator/health`
- 端口：8080

### 4.2 日志
- 位置：`logs/ai-customer-service.log`
- 级别：INFO
