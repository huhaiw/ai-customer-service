# 开发指南

## 一、环境要求

| 组件 | 版本 |
|------|------|
| JDK | 17+ |
| Maven | 3.8+ |
| MySQL | 8.0+ |
| Redis | 7.0+ |

## 二、项目结构

```
ai-customer-service/
├── ai-customer-service-api/          # API层
├── ai-customer-service-application/  # 应用层
├── ai-customer-service-domain/       # 领域层
├── ai-customer-service-infrastructure/ # 基础设施层
├── ai-customer-service-starter/      # 启动模块
├── deploy/                           # 部署配置
├── docs/                             # 文档
└── frontend/                         # 前端
```

## 三、开发规范

### DDD分层架构
- API层：Controller、DTO
- Application层：应用服务
- Domain层：实体、值对象、领域服务
- Infrastructure层：持久化、外部服务

### 数据表规范
必须包含字段：
- `delete_flag` (逻辑删除)
- `created_at` (创建时间)
- `updated_at` (更新时间)
- `created_by` (创建人)
- `updated_by` (更新人)

### 代码规范
- 遵循阿里巴巴Java开发规范
- 使用Lombok简化代码
- 禁止DDL语句，使用ORM

## 四、启动命令

```bash
# 编译
mvn clean compile

# 打包
mvn clean package -DskipTests

# 运行
java -jar ai-customer-service-starter/target/ai-customer-service-starter-1.0.0-SNAPSHOT.jar
```
