# AI智能客服 - 用户手册

## 一、功能介绍

### 1.1 智能对话
- 24小时在线服务
- 自动识别问题类型
- 智能生成回复

### 1.2 情绪识别
系统会自动识别您的情绪状态：
- Lv1：积极 😊
- Lv2：中性 😐
- Lv3：消极 😟
- Lv4：需要人工 😢

### 1.3 问题分类
自动分类您的问题：
- 订单问题
- 支付问题
- 退款问题
- 商品咨询
- 其他

## 二、使用方法

### 2.1 开始对话
1. 打开客服页面
2. 输入您的问题
3. 点击"发送"或按回车

### 2.2 转人工
如果AI无法解决您的问题，回复"转人工"即可接入人工客服。

## 三、常见问题

Q: AI回复慢怎么办？
A: 请检查网络连接，或刷新页面重试。

Q: 如何查看历史记录？
A: 历史记录保存在会话中，刷新页面后会话将重置。

Q: 问题解决后如何评价？
A: 可以对回复进行评分，帮助我们改进服务。
